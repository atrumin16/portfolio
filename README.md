## ✨ Features

- **🎨 Unified Corporate Design System:** Deep slate-navy tokens (`#080c14`), frosted glass mica layering, smooth border gradients, and high-contrast typography.
- **⚡ Zero-Lag Vite Performance:** Bundled and optimized via Vite 6 with aggressive asset minification, critical CSS inlining, and WebP/AVIF responsive images.
- **💻 Interactive Edge Terminal:** Embedded interactive CLI console showcasing skills, experience, certifications, and project links.
- **🌍 Internationalization (i18n):** Native bilingual switching (English & Spanish) with persistent user preference storage.
- **🛡️ Security & Performance Standards:** Strictly enforced Content Security Policy (CSP), automated cache headers, and DNSSEC validation.

---

## 🛠️ Tech Stack

- **Framework / Core:** Modern HTML5, Semantic CSS3 (Custom Variables), ES6+ Modules
- **Build Tooling:** Vite 6, Sharp (Image optimization)
- **Hosting / CDN:** Cloudflare Pages (Direct Git Integration & Wrangler CLI)

## 💻 Local Development

### Prerequisites
- Node.js 20+
- npm

### Setup
```bash
# Clone the repository
git clone https://github.com/atrumin16/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

### Production Build & Deploy
```bash
# Compile and bundle static distribution
npm run build

# Deploy to Cloudflare Pages
npm run deploy
```
