# Security Policy

## Reporting Vulnerabilities

If you discover a potential security vulnerability in this repository or associated infrastructure, please report it responsibly.

Do not create public GitHub issues for security-sensitive bugs or suspected data exposure.

### Contact

- Email: alberto@trujillomingorance.com
- Subject: `[Security] Vulnerability Report - Portfolio`

Please include:
- Description of the issue
- Steps to reproduce or proof-of-concept
- Affected URLs or endpoints
- Potential impact

You will receive an acknowledgment within 24 to 48 hours. Thank you for helping keep this project secure.
